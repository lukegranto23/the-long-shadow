# The Long Shadow

An unofficial, non-commercial fan game set in the world of *A Song of Ice and
Fire*, playable in the browser: **https://lukegranto23.github.io/the-long-shadow/**

Not affiliated with HBO or George R. R. Martin. Third-party assets are credited
in `assets/` (PBR-SOURCES.txt, models/DESTRIER-SOURCE.txt, MAKEHUMAN-CC0.txt,
EZ-TREE-LICENSE.txt); the dragon model is CC BY-NC, so this build must stay free.
